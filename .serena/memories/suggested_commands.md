# Suggested Commands

## Development
```bash
npm run dev        # Start dev server (Vite HMR)
npm run build      # Production build
npm run preview    # Preview production build
npm run lint       # ESLint check
```

## Running
- Dev server starts at http://localhost:5173 (default Vite port)
- Access from other devices on the same network via the local IP shown in terminal
