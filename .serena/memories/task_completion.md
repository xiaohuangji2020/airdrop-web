# Task Completion Checklist

1. **Lint**: `npm run lint` — fix any ESLint errors before considering done
2. **Build check**: `npm run build` — verify no build errors
3. **No test suite** configured in this project (no test scripts in package.json)
4. Verify dev server still runs: `npm run dev`
